Расширение для Chrome, Edge и Firefox, которое находит и маскирует персональные данные граждан РФ и секреты перед отправкой сообщения в ИИ-чат. Всё работает на устройстве, ничего не отправляется в сеть.

**Что внутри:** телефоны, адреса с индексом по справочнику Почты России, СНИЛС, паспорт РФ, банковские счета и карты, а также ключи API, токены и другие секреты из исходного проекта Offsend.

### Установка
- **Chrome и Edge:** скачайте `*-chrome.zip`, распакуйте в отдельную папку, откройте `chrome://extensions` (в Edge — `edge://extensions`), включите «Режим разработчика» и нажмите «Загрузить распакованное».
- **Firefox:** скачайте `*-firefox.zip`, откройте `about:debugging#/runtime/this-firefox` и нажмите «Загрузить временное дополнение». Без подписи Mozilla дополнение удаляется после перезапуска браузера.

Архив `*-sources.zip` — исходный код для проверки модераторами Firefox, для установки он не нужен.

Полный список изменений — в файле CHANGELOG.md в репозитории.
