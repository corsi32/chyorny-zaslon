# История изменений

## 0.4.0 — «Чёрный заслон»

Первая версия доработки браузерного расширения [Offsend](https://github.com/offsend/browser-extension) 0.3.0.

### Добавлено
- Детектор почтовых адресов РФ: регион, город, улица, микрорайон, дом, корпус, квартира, подъезд, этаж. Сокращения по приказу Минфина России № 171н. Адрес маскируется одним блоком.
- Проверка почтового индекса по справочнику Почты России, 61 317 индексов.
- Детекторы СНИЛС с контрольным числом, паспорта РФ, банковских счетов из 20 цифр.
- Проверка префикса и длины платёжной системы для карт, в том числе «МИР».
- Переключатели «Адреса (РФ)», «Паспорт РФ», «СНИЛС», «Банковские счета» в настройках, подписи на 6 языках, миграция настроек на версию 8.
- Нормализация текста из Word, с сайтов и из PDF: неразрывные пробелы и дефисы, тире, невидимые символы, полноширинные цифры.
- Разбор текста, склеенного при вставке: значения с прилипшими словами и цифрами соседних строк, цепочки из телефонов и карт.
- Тесты: размеченный набор из 72 текстов с метриками точности и полноты, 3000 случайных строк, нагрузочные тесты, бенчмарк, сквозные тесты ru-pii.
- Документация `docs/RU-DETECTORS.md`.

### Изменено
- Телефоны: строгие формы записи вместо «любых 7–15 цифр». Даты, суммы, ИНН и коды из чеков больше не считаются телефонами.
- Лимит времени скана действует только на пользовательские правила, встроенные детекторы всегда дорабатывают до конца.
- Лимит совпадений считает только принятые значения.
- Все повторы найденного значения маскируются, иначе сообщение нельзя было отправить.
- Новое название «Чёрный заслон», иконка, идентификатор для Firefox и ссылки.

### Результаты проверки
- 289 модульных тестов и 24 сквозных теста проходят.
- Точность и полнота на размеченном наборе — 0,980.
- Полный скан 50 000 символов — в среднем 35,5 мс.
