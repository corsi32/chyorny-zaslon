# Безопасность

«Чёрный заслон» — инструмент защиты данных, поэтому сообщения об уязвимостях важны.

## Как сообщить об уязвимости

**Не создавайте публичный issue для проблем безопасности.** Используйте закрытое
сообщение на GitHub: вкладка **Security → Report a vulnerability** в репозитории
https://github.com/corsi32/chyorny-zaslon/security/advisories/new

Укажите:
- в чём проблема и к чему она может привести;
- как её воспроизвести;
- версию расширения и браузер.

## Что особенно важно

- Любой путь, по которому содержимое сообщения или найденные значения покидают устройство: расширение спроектировано так, чтобы этого не происходило.
- Обход маскирования: данные, которые должны быть найдены, но уходят на сайт открытыми.
- Утечка исходных значений из локального хранилища, используемого для восстановления.

Уязвимости исходного проекта Offsend, не связанные с доработкой, лучше сообщать его авторам:
https://github.com/offsend/browser-extension/security
